# Egrit-Preflight v0.1.1

- When the L4T release declared by an image tag conflicts with the image's
  `L4T_VERSION` declaration, `target.l4t` is `UNKNOWN`. Agreeing declarations and
  comparisons with only one declaration keep their previous behaviour.
- Adds a companion vendor target-profile format and reference reader for recording
  what a source says about one hardware and software configuration. The CLI does
  not consume the companion format, and report schema v1 is unchanged.
- Package-description links point to the matching public documentation at an immutable
  revision rather than to paths relative to the package-index page.

These checks do not verify a Jetson GPU, its drivers, performance, or device
compatibility. A report can still require a physical target.
